# The Robot Pickup Line Championship

One pickup line in the voice of a robot trying to charm someone, under 200 characters, judged head to head by an AI judge on funniness. `main.ts` (Node 22, stdlib only, no network) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single line and a single sentence within the 200-character limit, reads it back and verifies the bytes match.

> "I ran a million simulations of meeting you, and in every single one, this was the best line I could come up with."
